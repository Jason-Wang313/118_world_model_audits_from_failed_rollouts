# Novelty Boundary Map

## What This Paper Can Claim

- Failed rollouts can be reused as mechanism-localized audits of missing world-model assumptions.
- Mechanism-localized audits can improve repair, diagnostic-probe, abstention, and fallback decisions under hidden physical shift.
- The local v5 benchmark supports this claim against scalar uncertainty, ensemble disagreement, conformal risk, active probing, causal-query repair, latent-MPC/PETS-style control, the previous failed-rollout audit, and other non-oracle baselines.

## What This Paper Cannot Claim

- Real-world robot deployment readiness.
- State-of-the-art robot world-model performance.
- A new general-purpose world model.
- A universal robotics benchmark.
- Full coverage of all possible failure mechanisms.

## Boundary Sentence

This work studies the planning value of localizing failed rollouts to missing physical mechanisms; it does not propose a new world model, a new robot benchmark, or validated sim-to-real deployment.
